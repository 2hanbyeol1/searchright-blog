# 서치라이트 | 블로그 포매터

서치라이트의 블로그 작성에 도움을 주는 포매터입니다.
Notion에서 내보내기한 html 파일을 정해진 포맷으로 변환해줍니다.

---

#### test

`vitest` : Vite를 기반으로 만들어진 빠르고 가벼운 테스트 프레임워크. Jest와 매우 유사한 API를 제공. 어설션(expect) 구문이나 테스트 구조가 거의 동일
`jsdom` : Node.js 환경에서 브라우저 환경처럼 DOM, 웹 API 등을 제공하는 라이브러리.
`testing-library/dom` : DOM 요소를 찾고 조작하고 상호작용하는 데 유용한 유틸리티 함수들을 제공하는 라이브러리
`testing-library/js-dom` : DOM 요소에 대한 Assertion(검증)을 더욱 쉽고 직관적으로 할 수 있도록 확장 기능들을 제공하는 라이브러리 (ex. toBeInTheDocument(), toHaveClass(), toHaveTextContent())
